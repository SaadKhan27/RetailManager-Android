# Retail Manager for Android

The Android app of Sentinel Retail Manager, the back office for RetailPOS.

## Install

On the Android phone, open this link (it always downloads the newest version):

**https://github.com/SaadKhan27/RetailManager-Android/releases/latest/download/RetailManager.apk**

and open the downloaded file. Android asks once to allow installing apps from the browser.
Then pair the phone with the till (RetailPOS > Settings > Installation > Phones).

## Updates

Install once. The app checks this page by itself and offers each new version; tap **Update**, then **Update** again
in Android's installer. The pairing and settings stay.

This repository holds the released APKs only.
